# Aura Documentation

The repository is the single source of truth. All documentation lives here as
version-controlled Markdown so that code and docs evolve together.

## Structure

```
docs/
├── product-bible/     # What Aura is and why (company, principles, PRDs)
├── architecture/      # How Aura is built
│   └── adr/           # Architecture Decision Records
├── engineering/       # How we work (standards, workflow, testing, devops)
└── templates/         # Reusable templates (feature, ADR, PR)
```
